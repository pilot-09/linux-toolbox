Bash/Linux

Bash ("Bourne Again SHell") is an interactive command interpreter and scripting language developed for Unix-like operating systems. It is designed as a free software alternative for the Bourne Shell (sh).

Linux is the operating system layer that provides the kernel, system services, and tools. Bash is one of the primary ways you interact with Linux, especially when working in a terminal. Together they form the core workflow for navigating files, running programs, and automating tasks.

This page will grow into a practical reference: the kind of commands and concepts you reach for when installing software, checking system health, or writing quick scripts. It's meant to be concise, useful, and easy to scan when you're in the middle of a task.

The programming style here is pragmatic and composable: small commands that do one thing well, connected through pipes and redirection to build larger workflows. Scripts tend to be short, focused, and optimized for clarity when you need results fast.

Common Bash Commands

  • ls - List directory contents.
  • cd - Change directory.
  • pwd - Print working directory.
  • mkdir - Make a new directory.
  • rmdir - Remove an empty directory.
  • rm - Remove a file or directory.
  • cp - Copy a file or directory.
  • echo - Print a line of text.
  • cat - Concatenate and display file contents.
  • mv - Move or rename files or directories.

Linux Notes

Linux is a family of open-source operating systems built on the Linux kernel. Most systems include GNU tools and a package manager to install software.

How Linux is Organized

Linux follows a standard filesystem layout so core files live in predictable places. Everything is treated as a file, including devices and many system interfaces.

  • / - Root of the filesystem.
  • /home - User directories and personal files.
  • /etc - System-wide configuration files.
  • /var - Variable data like logs and caches.
  • /usr - User programs and shared resources.
  • /bin and /sbin - Essential commands and system tools.

Bash Basics

Bash is the default shell on many Linux systems. It reads commands, runs programs, and can be scripted to automate repetitive tasks.

  • Pipes combine commands: ls | grep txt
  • Redirection sends output to files: echo hello > file.txt
  • Globbing matches patterns: rm *.log
  • History lets you reuse commands: press ↑ or use history

Permissions Overview

Linux uses user, group, and other permissions for files and directories. You can view them with ls -l and change them with chmod or chown.

  • r = read, w = write, x = execute
  • chmod 755 file sets common executable permissions
  • chown user:group file changes ownership
