# Harsh Critic Agent Memory

## Project Overview
- "Inner Shell" is a dystopian SF novel set in Belmont, a subscription-tier city, circa 2115
- Central mystery: I-07, a sentient being fused to tunnel infrastructure, broadcasts distress signals
- Three protagonists: Sol (solipsist investigator), Zara (coalition organizer), Null (empathetic Wanderer robot)
- Antagonist: Elara DeForest (R&D lead whose project created I-07)
- Resolution: fusion event creating entity called Echo

## Key Files
- Characters: `content/characters.html` (main review target)
- World context: `content/factions.html`, `content/history.html`, `content/infrastructure.html`

## Review Findings (2026-02-14) - see `review-findings.md`
- Systemic voice problem: zero dialogue samples across all characters
- Self-awareness epidemic: every character correctly diagnoses their own flaw
- Protagonist passivity: Sol perceives but never acts with consequences
- Emotional monotone: all characters occupy "thoughtful suffering" register
- Convergence risk: all arcs terminate in one tunnel scene
