Python

Python is a high-level programming language focused on readability and rapid development. Its clear, concise syntax makes it easy to learn and effective for building both small scripts and large applications.

The language balances simplicity with power: it includes a rich standard library, supports multiple programming styles (procedural, object-oriented, and functional), and runs across Windows, macOS, and Linux.

It is used for:

  1. Web development (server-side)
  2. Software development
  3. Mathematics
  4. System scripting (automation)
  5. Data analysis and visualization

What can Python do?

  1. Can be used on a server to create web applications.
  2. Can be used alongside software to create workflows.
  3. Can connect to database systems. It can also read and modify files.
  4. Can be used to handle big data and perform complex mathematical operations.
  5. Can be used for rapid prototyping, or for production-ready software development.

Why Python?

  1. Python works on different platforms (Windows, Mac, Linux, Raspberry Pi, etc).
  2. Python has a simple syntax similar to the English language.
  3. Python has syntax that allows developers to write programs with fewer lines than some other programming languages.
  4. Python runs on an interpreter system, meaning that code can be executed as soon as it is written. This means that prototyping can be very quick.
  5. Python can be treated in a procedural way, an object-oriented way or a functional way.

Python syntax compared to other programming languages

  • Python was designed for readability, and has some similarities to the English language with influence from mathematics.
  • Python uses new lines to complete a command, as opposed to other programming languages which often use semicolons or parentheses.
  • Python relies on indentation, using whitespace, to define scope; such as the scope of loops, functions and classes. Other programming languages often use curly brackets for this purpose.
